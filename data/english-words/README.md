# Английские слова для вкладки «Языки»

Колода для сервера: 2690 частотных английских слов в порядке частотности, у каждого — транскрипция, перевод, неправильные формы, пример и перевод примера. Служебные слова (артикли, местоимения, предлоги, союзы, be / do / will / would / shall, not, something / nothing и т. п. — 119 слов) убраны: их учат в контексте и по грамматике, а не карточками. Модальные can, could, may, might, must, should, ought остались. Задача для бека — в `obsidian-done/Сделал-получил/Идеи.md`, п. 37.

## Файлы

- `english-words.json` — массив, одно слово на строку.
- `english-words.csv` — то же для импорта в таблицу (UTF-8, с заголовком).

## Поля

| Поле | Тип | Что это |
|---|---|---|
| `rank` | number | Номер в колоде, 1…2690, без пропусков; по нему выдаются порции. |
| `ngslRank` | number | Место в исходном списке NGSL (со служебными словами). |
| `word` | string | Слово (лемма), строчными. |
| `transcription` | string | Произношение, американская норма, IPA без косых черт (`ɡoʊ`). Из словаря CMUdict; у омографов выбран вариант под наш перевод (`lead` — liːd «вести», `wind` — wɪnd «ветер»). |
| `translation` | string | Перевод на русский: главные значения через запятую. |
| `forms` | string \| null | Формы, которые не выводятся по правилам: `went, gone`, `children`, `better, best`. Есть у 123 слов. |
| `collocations` | `{ en, ru }[]` | Два типичных сочетания с переводом: `make a decision — принять решение`. В CSV — одной строкой через `; `. |
| `example` | string | Пример на английском с этим словом (может быть в другой форме: `went` для `go`). |
| `exampleTranslation` | string | Перевод примера. |
| `exampleSource` | string | `tatoeba:<id>` — предложение с tatoeba.org, `manual` — написано вручную. |
| `kidSafe` | boolean | `false` — слово детям лучше не выдавать (alcohol, gun, abortion…), 24 слова. |

## Откуда

- Список и порядок — **NGSL 1.2** (New General Service List, newgeneralservicelist.com), лицензия CC BY-SA 4.0. 2809 слов покрывают около 92% слов в обычных текстах.
- Примеры — **Tatoeba** (tatoeba.org), лицензия CC BY 2.0 FR. Для каждого слова выбрано короткое предложение, в котором остальные слова по возможности уже пройдены (ранг не больше, а для первых 200 слов — из первых 200).
- Транскрипция — **CMUdict** (Carnegie Mellon Pronouncing Dictionary, лицензия BSD), переведена из ARPAbet в IPA автоматически.
- Неправильные формы — из лемматизированного списка NGSL, правильные (‑s, ‑ed, ‑ing) и британские написания отброшены.
- Переводы слов, сочетания и примеры с `exampleSource: manual` (первые 500 слов — почти все, простые детские фразы) — написаны вручную.

При показе в приложении нужна строка об источниках (например, в «О приложении»): «Список слов — NGSL (CC BY-SA 4.0), примеры — Tatoeba (CC BY 2.0 FR), транскрипция — CMUdict».

## Можно ли больше

Да. У авторов NGSL есть продолжение по той же частотности — около 31 000 слов (NGSL + SFI). Следующие тысячи слов собираются тем же способом: примеры из Tatoeba, переводы вручную. Для детей обычно хватает этих 2690: дальше идут редкие и узкие слова.

## Что проверить человеку

Примеры из Tatoeba — живые фразы, иногда разговорные или с вольным переводом. Примеры первых 500 слов уже просмотрены: неудачные (взрослые, идиомы, вольный перевод) заменены, это 386 слов. Плохой пример меняется в одной строке, `exampleSource` — `manual`.
