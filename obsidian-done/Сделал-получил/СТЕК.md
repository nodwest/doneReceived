База: Expo + RN
Интерфейс: Reusables(Shadcn UI) + Tailwind - косим под Module CSS
Данные: MMKV + Expo SecureStore + Zustand + TanStack Query



- TanStack Query:
    - Весь CRUD с бэкендом (tasks, notes, profile), когда он появится.
- Zustand:
    - UI‑состояние (фильтры, выбранный таск, модалки, theme),
    - возможно, «рабочий снэпшот» выбранных сущностей, если нужно быстро менять локально.
- MMKV:
    - настройки (theme, language),
    - лёгкий оффлайн‑кэш,
    - временные заметки до появления бэкенда.
- SecureStore:
    - access/refresh tokens, сторонние ключи (OAuth и т.п.).
