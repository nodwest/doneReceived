# Навыки агента для DoneReceived

Навыки Claude Code для этого репозитория. Агент видит название и описание каждого навыка, а полный текст подгружает, только когда задача ему подходит. Правила `CLAUDE.md` важнее навыков.

## Свои (`dr-*`)

Основа — навыки бэкендера из заметки `obsidian-done/Сделал-получил/Навыки Codex для DoneReceived.md`. Здесь они переписаны под клиент: подробные правила остаются в `CLAUDE.md`, навыки содержат порядок проверки и ссылки на код.

| Навык                    | Когда срабатывает                                                      |
| ------------------------ | ---------------------------------------------------------------------- |
| `dr-client-state`        | запросы, мутации, кэш, Zustand, хранилища, сессия                      |
| `dr-i18n-accessibility`  | любой текст и интерактивный элемент интерфейса                         |
| `dr-mobile-api-security` | вход, токены, коды, хранилища, разрешения, логи; проверка безопасности |
| `dr-expo-testing`        | настройка и написание тестов, проверка готового интерфейса             |

Что изменено при копировании:

- В начало каждого готового навыка добавлена заметка «DoneReceived»: правила `CLAUDE.md` важнее навыка, и перечислено, где проект отличается — стили, свои шапки, dev-build, FSD.
- Из навыков Expo убран раздел «Submitting Feedback». Он велит агенту самому отправлять в Expo отзывы с контекстом задачи через `npx @expo/agent-cli`.
- Не скопированы `agents/openai.yaml` — это настройки Codex.
- У Vercel оставлены только правила `rules/`, без сводного `AGENTS.md`.
- У `security-best-practices` оставлены только справочники для веб-фронтенда и React.

Сознательно не поставлены:

- **`expo-native-ui`** противоречит правилам проекта: inline-стили вместо `StyleSheet`, Expo Go вместо dev-build, системные цвета вместо наших токенов, заголовки стека вместо своих шапок.
- **`expo-dev-client`** почти целиком про облачные сборки EAS, которыми проект не пользуется.
- **Серверные навыки** — NestJS, Drizzle, PostgreSQL, эксплуатация — относятся к бэкенду, а не к этому репозиторию.

Чтобы обновить готовый навык, скачайте его заново из источника, повторите правки из списка выше и обновите коммит в таблице.
